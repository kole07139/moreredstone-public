### New Blocks:


- **Relays:** A variant of the classical Vertical-Diode blocks in Minecraft which will **bypass the downward block transmission**. Crafted with 1 central amethyst shard bounded by 4 blocks of the same Vertical-Diode block (Slab, Stairs, Glasses...).

***→ Fun fact:** now the longest name in Minecraft will be: "Relay Waxed Weathered Cut Copper Stairs"*


- **Redstone Lantern:** A simple redstone variant of the lantern, inspired to the block models of [Redstone Lantern](https://modrinth.com/mod/redstonelantern) Mod. It is more powerful compared to the Redstone Torch, as the Lantern variant will strongly power not only the upper block, as the Redstone Torch does, but every neighbor block exception made for the block on which the lantern has been attached to. Also, the Redstone Lantern burnout will be doubled in time, resulting not in 8 clocks but 16 clocks.
